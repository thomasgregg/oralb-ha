# v0.7.36b1 — Protocol 6 battery diagnostics

Diagnostic beta for #33. This build captures the wire values needed to identify the protocol 6 battery layout; it deliberately does not change battery decoding yet.

## Changes

- Records the most recent raw FF05 battery payload and its transport source.
- Records the most recent raw FF29 retained-session payload.
- Exposes ff05_raw, ff05_source, ff29_raw, protocol_version, and firmware_revision on the Battery entity.
- Logs successful FF05 and FF29 reads when debug logging is enabled.
- Documents and regression-tests the diagnostic attributes.

## Validation completed

- 166 unit tests passed locally.
- GitHub unit tests passed.
- HACS validation passed.
- Hassfest validation passed.

## Test procedure for #33

1. In HACS, enable pre-releases for Oral-B Live or choose v0.7.36b1 under Need a different version. Restart Home Assistant.
2. Wake the brush and complete one normal brushing session.
3. Open the Battery entity and copy its complete attributes, especially ff05_raw, ff05_source, ff29_raw, protocol_version, firmware_revision, and source.
4. Note the percentage shown on the handle immediately after the session and attach the values to #33.

The raw payloads contain brush telemetry only; they do not contain cloud credentials.
