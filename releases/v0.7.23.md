# v0.7.23 — Retry retained-session recovery

## Changes

Fix session recovery after an immediate retained-record sync fails.

- Keep unresolved session generations pending until a genuinely new FF29 record is applied.
- Retry later with bounded 1-minute, 5-minute, and 6-hour backoff instead of creating a connection storm.
- Hand recovery safely to a verified iO Sense and handle concurrent or back-to-back sessions.
- Add regression coverage for failures, duplicates, invalid records, backoff, charger handoff, and generation races.

Live-validated on Home Assistant 2026.8.2 with an iO Sense: a failed immediate FF29 read preserved the 73-second session, incremented the daily count exactly once, and did not produce a false 0% battery value.
