# Fix Home Assistant signal unit import

## Compatibility fix

- Fixes startup on current Home Assistant releases where `UnitOfSignalStrength` is no longer available from `homeassistant.const`.
- Uses the supported `SIGNAL_STRENGTH_DECIBELS_MILLIWATT` constant for the iO Sense Wi-Fi RSSI sensor.
- Resolves the `ImportError` that prevented the entire Oral-B Live sensor platform from loading.

Bluetooth, charger bridge and session behavior are unchanged.
