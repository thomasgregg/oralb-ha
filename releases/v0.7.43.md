# Restore updates from passive Bluetooth scanners

## Changes

- Brush state, brushing time, sector and pressure now update when the only scanner in range can receive advertisements but cannot connect. Previously, the displayed values could freeze after setup.
- While direct GATT or the iO Sense bridge supplies live brushing data, delayed advertisements can still refresh identity and signal strength without overwriting the session.
- Direct brush reads and iO Sense bridge features require a connection-capable Bluetooth adapter or proxy.

Thanks to @mtheli for reporting and testing the passive-scanner behavior in [issue #53](https://github.com/thomasgregg/oralb-ha/issues/53).

## Validation

All 509 tests pass on Home Assistant 2024.4.4 and 2026.8.3. The 21 regression cases cover cached startup, passive-only and mixed scanner sources, session tracking, delayed packets during GATT, and charger availability. The automated tests simulate Bluetooth transport.

## Install

On Home Assistant 2026.11 or later, install the **v0.7.43** update under
**Settings → Updates**. On earlier versions, update Oral-B Live in HACS.
Restart Home Assistant after updating.
