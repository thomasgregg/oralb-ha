# v0.7.0 — Local iO Sense bridge

## Changes

- Automatically discovers an iO Sense and verifies its paired toothbrush by MAC address.
- Uses the charger as a local, read-only live-data bridge in Charger/app compatible mode.
- Reads pressure every second and alternates timer and zone reads, with local timer advancement between brush anchors.
- Keeps Home Assistant direct as the second connection option; no third mode was added.
- Reconciles the exact 21-byte FF29 retained-session summary without double-counting sessions.
- Adds complete last-session pressure, target, battery and session-ID attributes.
- Adds a separate iO Sense device with charger, Wi-Fi, cloud, clock, display, light and policy diagnostics.
- Adds missing brush modes, smileys, zero-based charger-zone decoding and signed battery current.
- Rewrites the README around the current architecture and adds a full local protocol reference.

## Safety and privacy

All runtime communication is local and read-only. The integration does not use Oral-B cloud credentials and does not write charger, light, network, update or brush settings.
