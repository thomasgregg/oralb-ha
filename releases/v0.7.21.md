# Background sync and retained-session validation

## Changes

- Schedule the post-session sync sequence as a named Home Assistant background task so settle delays and retries do not hold up bootstrap.
- Validate FF29 session timestamps and durations before applying `battery_end`, preventing uncommitted records from briefly reporting a bogus 0% battery.
- Preserve battery refreshes from valid duplicate session records.
- Resolves #10. Thanks to @Heronidas for the detailed diagnosis and device testing.
