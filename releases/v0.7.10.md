# v0.7.10 — Improve toothbrush device naming

## Device naming

- Replaces MAC-only default toothbrush names with a descriptive model-based name.
- Appends the final four address characters so multiple brushes remain distinguishable.
- The tested brush is now named `iO Series Toothbrush 64D3`.
- Uses `Oral-B Toothbrush <suffix>` when the model is not yet known.
- Applies the same naming to Bluetooth discovery, manual setup and the Home Assistant device record.
- Home Assistant user-assigned device names remain untouched.
