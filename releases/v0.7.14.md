# v0.7.14 — Pacer compatibility and charger reliability

## Changes

- Align Toothbrush Card entities with the official Oral-B timed-pacer semantics while keeping experimental physical-position diagnostics separate and disabled by default.
- Refresh pressure, battery, brush-head state, smiley, and identity data more reliably through the iO Sense charger bridge.
- Prevent stale cached brush state from creating false sessions and preserve accurate retained-session timestamps across delayed charger reads.
- Display handle firmware in the same composite format as the Oral-B app and decode the verified controller metadata offsets.
- Consolidate technical packet layouts, command details, benchmarks, and motion research in the standalone protocol reference.
- Add malformed/truncated payload and motion resampling edge-case coverage.
