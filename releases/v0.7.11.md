# Live timer and pacer updates

## Changes

- Advance the brushing timer, pacer sector, and sector timer locally at 1 Hz so slow charger requests no longer delay the Home Assistant display.
- Read the configured FF26 pacer schedule at session start and use FF09 as the authoritative sector/timer correction.
- Expose FF09 elapsed-sector seconds in charger and direct modes.
- Reset Sector and Sector timer when brushing stops instead of retaining stale values.

- 21 protocol regression tests passed.
- Python compilation, manifest validation, and diff checks passed.
