# IO Sense diagnostic probe

## iO Sense diagnostic probe

- Add a standalone tool that automatically discovers likely iO Sense chargers and records complete portable advertisement fields.
- Capture the GATT service, characteristic and descriptor layout, including safe readable values and individual errors.
- Probe the known charger transport with a deliberately small GET-only identity snapshot; no POST/SET command or command payload is sent.
- Save an issue-friendly JSON report that preserves unknown advertisement and GATT variants for future device support.
- Add detailed macOS, Linux and Windows setup, safety, privacy, troubleshooting and result-interpretation documentation.
- Publish `iosense_probe.py` as a downloadable release asset alongside the HACS integration ZIP.

This release adds diagnostics and documentation; it does not change integration runtime behavior.
