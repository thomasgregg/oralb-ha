# SmartRing color sensor

## Changes

- Add an enabled-by-default SmartRing color sensor to the toothbrush device with the agreed `ring_color` translation key and uppercase `#RRGGBB` state.
- Restore the last handle color across Home Assistant restarts and expose the uninterpreted fourth FF2B byte as an attribute.
- Read handle characteristic `FF2B` through direct connections, quiet charger-priority brush syncs, and the iO Sense post-session passthrough path.
- Keep the handle SmartRing value separate from the iO Sense charger's native `charger_ring_color` value and preserve the integration's read-only safety boundary.
- Resolves #2. Thanks to @mtheli for the protocol findings and the Toothbrush Card entity contract.

- Python compilation, changed-file Ruff checks, manifest JSON validation, and diff checks passed.
- HACS and Hassfest validation passed on the release commit.
