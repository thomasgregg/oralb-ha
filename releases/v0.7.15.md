# v0.7.15 — Live pressure scheduling and session summaries

## Changes

- Restores the proven two-read iO Sense live schedule so FF0B pressure is sampled before the auxiliary timer/pacer/configuration read.
- Saves the observed brushing mode and a complete locally sampled pressure summary for each live session, then refines it with the exact retained FF29 record when available.
- Removes the short-lived experimental mouth-position entities and cleans obsolete duplicate pacer entities during integration reload.
- Keeps the decoded FF0D and mouth-position research in the protocol reference without running the proprietary-model experiment in Home Assistant.

## Compatibility

- Toothbrush Card continues to use the same `brushing_time`, `sector`, `number_of_sectors`, `pressure`, `mode`, battery and `routine_length` contract.
- Charger/app compatible and Home Assistant direct remain the only user-facing connection choices.
